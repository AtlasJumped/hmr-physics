# HMR Physics

The physics of the Holistic Model of Reality (HMR). The readable version lives at the HMR source pages; this repository holds the versions, derivations, and the scripts behind the numbers, so anyone can check them.

## Versions

| Version | Date | Status |
|---|---|---|
| V1 | 2026-11-20 | Live on the site. Growth rule with steady exponential growth; interference between pairs of histories and none between triples; 12 matches with published physics |
| V2 | in progress | A two-member council (mathematics and physics) is extending the model from a set of thoughts to a mechanics of thinking. Notes will be added here when V2 is published |

## Results so far, labeled

- **Measured here (2026-11-22):** the K-parent growth rule does not hold a fixed dimension; the estimate drifts upward as the pattern grows (`scripts/2026-11-22/kparent_dim.py`).
- **Measured here (2026-11-22):** in V1's family of growth rules, the order among later thoughts is statistically independent of the order among earlier ones, so no record or persistent particle can form (`scripts/2026-11-22/nomemory_check.py`). A law that depends on shape is needed.
- **Measured here (2026-11-22, toy size):** a multi-scale balance rule moves a 60-thought pattern toward a true two-dimensional scatter but does not reach it (`scripts/2026-11-22/balance_mcmc.py`).
- **Open:** three-dimensional space, particles, mass ratios, and why the first distance is one Planck length are not yet derived.

## How to check

Each script runs with Python 3 and numpy. Outputs from our runs are saved beside each script with the same name and `_out`.
